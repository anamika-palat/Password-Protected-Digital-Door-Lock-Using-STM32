🔐 Password-Protected Digital Door Lock Using STM32

📌 Project Overview

The Password-Protected Digital Door Lock is an embedded systems project developed using an STM32 microcontroller. The system provides secure door access through password-based authentication. It is programmed using Arduino IDE.

🎯 Objectives

- To develop a password-based digital door locking system.
- To improve security through electronic access control.
- To explore STM32 microcontroller programming and embedded systems.

🛠️ Technologies Used

- STM32 Microcontroller
- Arduino IDE
- Embedded C/C++
